# 0001. Stack: Django REST + Flutter + Next.js
- Sana: 2026-10-13 · Holat: qabul qilingan (loyiha egasi tanlovi)

**Qaror.** Backend — Django 5.2 + DRF + PostgreSQL. Kassa — Flutter (Windows desktop, Android, iOS), lokal baza SQLite (Drift). Admin dashboard — Next.js (App Router, TypeScript).

**Sabab.** Bitta Flutter kod bazasi desktop va mobil uchun; Django — tayyor auth, ORM, migratsiyalar; Next.js — admin panel uchun boy ekotizim (shadcn/ui, jadvallar, grafiklar). OpenAPI orqali Dart va TS klientlar generatsiyasi API kelishmovchiligini kamaytiradi.

**Oqibat.** Uch til (Python, Dart, TypeScript). API shartnomasi faqat OpenAPI sxemasida; klientlar qo'lda yozilmaydi.
