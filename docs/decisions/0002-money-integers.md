# 0002. Pul va miqdor butun sonlarda
- Sana: 2026-10-13 · Holat: qabul qilingan

**Qaror.** Pul — tiyinda (`bigint`/`int`), miqdor — `qty_milli` (1/1000 birlik). Float/double taqiqlangan. Bo'lish va yaxlitlash bitta yordamchi funksiyada (half-up), Python va Dart'da bir xil testlar bilan.

**Sabab.** Float xatolari kassada noto'g'ri qaytim va hisobotlarga olib keladi.
